## 🗄️ Database Setup (Hostinger MySQL)

If you are using a backend script (e.g. PHP) to handle contact forms or student inquiries on Hostinger:

### 1. Database Credentials

| Setting | Value / Variable | Notes |
| :--- | :--- | :--- |
| **Host** | `localhost` | Always `localhost` on Hostinger |
| **Database Name** | `uXXXXXXXXX_vijigishu` | Created in Hostinger hPanel |
| **Database User** | `uXXXXXXXXX_user` | Created in Hostinger hPanel |
| **Database Password** | `[Your Database Password]` | Set in Hostinger hPanel |

### 2. Sample PHP Database Connection (`db.php`)

```php
<?php
$host = 'localhost';
$db   = 'uXXXXXXXXX_vijigishu';
$user = 'uXXXXXXXXX_user';
$pass = 'YOUR_DB_PASSWORD';
$charset = 'utf8mb4';

$dsn = "mysql:host=$host;dbname=$db;charset=$charset";
$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
     $pdo = new PDO($dsn, $user, $pass, $options);
} catch (\PDOException $e) {
     throw new \PDOException($e->getMessage(), (int)$e->getCode());
}
?>
```

### 3. Sample Inquiries Table Schema (SQL)

```sql
CREATE TABLE IF NOT EXISTS `inquiries` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `full_name` VARCHAR(255) NOT NULL,
  `email` VARCHAR(255) NOT NULL,
  `phone` VARCHAR(50) DEFAULT NULL,
  `program` VARCHAR(100) DEFAULT NULL,
  `message` TEXT,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 🚀 Deployment Instructions (Hostinger)

### Option A: Auto-Deployment via GitHub
1. Open **Hostinger hPanel** ➔ **Advanced** ➔ **Git**.
2. Set **Repository:** `https://github.com/Shivam1101/vijigishu-website.git`
3. Set **Branch:** `main`
4. Set **Target Directory:** `public_html` (or your subdomain folder like `public_html/subdomain`).
5. Copy the SSH Key generated by Hostinger and add it to your [GitHub Deploy Keys](https://github.com/Shivam1101/vijigishu-website/settings/keys).
6. Click **Deploy**. Any future `git push` via GitHub Desktop will automatically deploy live.

### Option B: Local Testing
Run a local web server to preview changes:
```bash
npx http-server . -p 3000
```

### 2. Typography Styles

* **Primary Heading Font**: `'Playfair Display', serif`
  * *Usage*: Section Headings (`h2`), Page Titles (`h1`), high-impact italic emphasis.
  * *Feel*: Elegant, editorial, prestigious, representing high-quality global academics.
* **Primary Body Font**: `'Plus Jakarta Sans', sans-serif`
  * *Usage*: Body text (`p`), destination tags, navigation links, forms, descriptions.
  * *Feel*: Modern, clean, highly legible, clean geometric rendering.
